## Задание
Оформить страницу из ЛР №1 с помощью внешнего CSS-файла (style.css) в стиле «киберпанк»: тёмный фон, неоновые цвета, текст с обводкой через text-shadow, глитч-эффект при :hover на карточках, отключение обводки при :active.

## Содержимое репозитория
- `index.html` — страница из ЛР №1, оформленная по варианту 20;
- `style.css` — внешний файл стилей (основной стиль);

- `README.md` — описание работы.

## Что реализовано

### Три способа подключения стилей
1. **Внешний файл** — `<link rel="stylesheet" href="style.css">`: весь основной стиль страницы;
2. **Inline-стиль** — `style="overflow: hidden;"` на элементе `<main>` (контейнер с глитч-эффектом, по варианту 20);
3. **Внутренний блок** — одно правило в `<style>`: стили заголовков (нестандартный шрифт, размер, межбуквенный интервал).

### CSS-переменные
Объявлены в `:root`: цвета (глубокий чёрный фон, электрический голубой акцент, неоновые фиолетовый и пурпурный, цвета текста) и шрифты. Используются во всех правилах `style.css` без дублирования значений.

### Позиционирование
- `position: static` — карточки контента (`.card`);
- `position: relative` — шапка `<header>` (якорь для бейджа);
- `position: absolute` — бейдж `.badge` внутри шапки.

### Состояния элементов
- `:hover` — глитч-эффект на карточках (смещение текста по осям X/Y через анимацию + расхождение text-shadow), подсветка ссылок и кнопки;
- `:active` — отключение обводки текста (`text-shadow: none`);
- `:focus` — неоновая подсветка полей формы и ссылок;
- `:visited` — посещённые ссылки неоново-фиолетовым цветом.

### Контрастность (не менее 4.5:1)
